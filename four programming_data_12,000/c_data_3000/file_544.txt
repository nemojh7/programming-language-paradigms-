    struct fd f = fdget(fd);
    ssize_t ret = -EBADF;
    if (f.file) {
        loff_t pos = file_pos_read(f.file);

        file_pos_write(f.file, pos);
        fdput(f);

And it keeps going until the last internal function is called. The return value you receive from calling libc's read function is returned from the functions above.

You could alternatively work from left to right. So you don't need to reverse the string. You could also test if a bit is set by a bit shifting operation combined with a bit test like this:
bool n = (acc >> (unsigned)index) & 1u;

With bit operations it's recommended to work with unsigned values. The number of bits to convert could be a parameter to your function, so the signature could look like this:
void convert_to_binary(unsigned acc, int bits, char *bin) 

The loop is based on the number of bits and not the number of characters to be written, so that after every 4th output of an bit an additional space character is output, so that % 4 can be used here.
This would look like this then:
void convert_to_binary(unsigned acc, int bits, char *bin) {
    char *ptr = bin;
    for(int index = bits - 1; index >= 0; index--) {
        bool n = (acc >> (unsigned)index) & 1u;
        *ptr++ = n ? '1' : '0';
        if(index % 4 == 0)
            *ptr++ = ' ';
    }
    *ptr = '\0';
