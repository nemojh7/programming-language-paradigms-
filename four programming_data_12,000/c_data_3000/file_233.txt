Unless it is the operand of the sizeof or unary & operators or is a string literal used to initialize a character array in a declaration, an expression of type "N-element array of T will be converted, or "decay", to an expression of type "pointer to T" and the value of the expression will be the address of the first element of the array.

Is a sub loop of this:
for ( i = 0 ; i < N ; i++ )

You cannot change the value of i in the sub loop, and reasonably expect that doing so will not adversely affect the value assignments of any variable that references it as an index.  Including the likely occurrence of Undefined Behavior when the index write to memory that you do not own.
The take away here is to pay attention to the indices in use and do not double increment them.  If needed, choose a different index variable to use inside sub loops to avoid over-writing those in the outer loop.

In the earliest versions of C (known as K&R C) the void type did not exist, and there was no way to declare a "generic" pointer like void *. That changed in the 1989 standard, which introduced the void type and created the rule that void * could be directly assigned to other pointer types, making the cast redundant.  So from C89 onward, you can write:
/** C89 and later */
int *ptr = malloc( sizeof *ptr * N );
