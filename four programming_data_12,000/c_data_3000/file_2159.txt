target is the name of the file you want to build. So the line

Is trying to build a file called program. However, the command does not create a file called program, it creates a file called Client. This is less of a problem than you might think, it just means that the rule is always executed whether Client is up to date or not. However, you should change it so the target is the file you are building.
Client: client.o
    gcc client.o -o Client

By the way, in most *nixes, file names are case sensitive Client and client are different files on Linux, for example.
That rule has a single dependency: client.o. Unfortunately, your make file does not know how to build client.o - there is no target called client.o.

#include <stdlib.h>
#include <string.h>

typedef struct Lookup Lookup;

struct Lookup
{
    size_t rows;
    size_t cols;
    char **data;
};

static void Lookup_destroy(Lookup *self)
{
    if (!self) return;
    for (size_t r = 0; r < self->rows; ++r)
    {
        free(self->data[r]);
    }
    free(self->data);
    free(self);
}

static Lookup *Lookup_create(size_t rows, size_t cols)
{
    Lookup *self = malloc(sizeof *self);
    if (!self) return 0;

    self->rows = rows;
    self->cols = cols;
    self->data = malloc(rows * sizeof *(self->data));
    if (!self->data)
    {
        free(self);
        return 0;
    }
    memset(self->data, 0, rows * sizeof *(self->data));
    for (size_t r = 0; r < rows; ++r)
    {
        self->data[r] = malloc(cols * sizeof *(self->data[r]));
        if (!self->data[r])
        {
            Lookup_destroy(self);
            return 0;
        }
    }

    return self;
}

static Lookup *Lookup_resize(Lookup *self, size_t rows, size_t cols)
{
    if (!self) return Lookup_create(rows, cols);

    // free rows that are no longer needed, if any:
    for (size_t r = rows; r < self->rows; ++r)
    {
        free(self->data[r]);
        self->data[r] = 0;
    }

    // reallocate array of rows:
    char **newdata = realloc(self->data, rows * sizeof *newdata);
    if (!newdata)
    {
        Lookup_destroy(self);
        return 0;
    }

    // update row array and row count: 
    self->data = newdata;
    size_t oldrows = self->rows;
    self->rows = rows;

    // initialize new rows to NULL, if any:
    if (rows > oldrows)
    {
        memset(self->data + oldrows, 0,
                (rows - oldrows) * sizeof *(self->data));
    }

    // reallocate individual rows:
    for (size_t r = 0; r < rows; ++r)
    {
        char *newrow = realloc(self->data[r], cols * sizeof *newrow);
        if (!newrow)
        {
            Lookup_destroy(self);
            return 0;
        }
        self->data[r] = newrow;
    }

    // update col count:
    self->cols = cols;

    return self;
}

This is actually not quite true; the permutation occurs after the last option is scanned, as you have seen in your example. But the effect is the same; argv is permuted so that nonoptions are at the end, and optind is modified to index the first nonoption.

In this case, no permuting is done and optind's value is preserved.
Setting POSIXLY_CORRECT has other consequences, documented here and there in the manpages for various Gnu utilities. My habit is to use + as the first character of the option string (unless I actually want non-Posix behaviour), but arguably setting the environment variable is more portable.

Before getting to your original question of how to allocate 2D arrays and pass it to another, your code is broken in several ways that make it difficult to talk about your original point.  Let us fix them first before getting to the point.
First and foremost, by having statement like ptr[j][i] = ' ', you presumably want to have a 2D array of chars, in which case you should declare ptr as such.
char ptr[8][8]; // 2D array of chars

not
char** ptr[8][8];  // 2D array of pointers to pointers to chars

Second if you want to return the array (ptr) you created inside createMapBorad, then you need to return ptr, not **ptr.  i.e.,
return ptr;

not
return ** ptr;

The expression ** ptr dereferences the ptr twice, which is equivalent to ptr[0][0] in this case, which will return 'F' (0x46) disguised as if it is a pointer to pointers to chars (char ** ).  your printMapBoard then accesses the address 0x46, which causes segfault.  This is almost certainly not what you meant to do.
After fixing them, if you want to return a "2D array of chars" rather than an array of pointers, you need to have createMapBoard return char* rather than char** .  char** is an array (pointer) of pointers (to chars).
So far, you at least need to fix createMapBoard to:
char * createMapBoard(void) {
    char ptr[8][8];
    ...
    return (char *)ptr;
}

(We are not done yet. stay tuned).
BTW, it would have been nice if you can say a function returns a 2D array, not char* (which is essentially 1D array, so you cannot do things like a[i][j]), but AFAIK C does not allow us to do this.  The following (hypothetical) code is a syntax error.
char[8][8] createMapBoard(void) {
    char ptr[8][8];
    ...
    return ptr;
}

So you need to pretend you return a regular 1D array (char* ).  You can cast it later to the real 2D array later (we are getting to it shortly).
After fixing createMapBoard this way, you are still making an error of returning a local array as the return value.  This is wrong because the lifetime of local arrays is limited to the end of the function invocation.  So the code
char * createMapBoard(void) {
    char ptr[8][8];
    ...
    return (char *)ptr;
}

is syntactically OK, but prints wrong results.
You need to call malloc to create an array that is alive after you return from the function, like:
char * createMapBoard(void) {
    char * ptr = (char *)malloc(sizeof(char) * 8 * 8);
    ...
    return ptr;
}

But then ptr essentially becomes a 1D array inside createMapBoard function, which makes assignments like
ptr[i][j] = ' '

no longer valid.
The way you can make ptr a 2D array is this:
char (*ptr)[8] = (char (*)[8])malloc(sizeof(char) * 8 * 8);

which is supported from C99 standard.
This way, the compiler understands ptr is a pointer to a 2D array whose number of elements in each row is eight (so it can correctly calculate the address of a[i][j]).
You can have printMapBorad simply take an argument of char[8][8] like this:
void printMapBorad(char board[8][8]) {
   ...
}
