{
  static KeyState lastState = 0;
  static KeyState lastValidState = 0;
  static Timestamp lastTimestamp = 0;
  KeyState currentState = 0;
  uint8_t x, y;

  if (upKeys)

  if (downKeys)

  {
    // Set appropriate row pin to H
    SetRowPinH(y);
    // Just to be sure that any parasitic capacitance gets charged
    SleepMicro(10);

    {
      // Check key pressed
      if (IsColPinSet(x))
        currentState |= 1 << ((y * COL_COUNT) + x);
    }

  // Matrix state should not change for some time to accept result
  if (lastState == currentState)
  {
    // Check if time has passed
    if ((TimestampNowMilli() - lastTimestampMilli) >= DEBOUNCE_TIMEOUT)
    {

      if (upKeys)

  }
  lastState = currentState;

For example, the way the Standard defines "based upon", the expression (p1 == p2) ? p3 : p4 would be "based upon" p1 if p1==p2 and p3!=p4, since replacing p1 with a pointer to identical data would change the value of the expression. Operations using lvalues which are at least potentially derived from a restrict-qualified pointer and occur within its lifetime are sequenced with regard to each other and the beginning and end of that lifetime, and operations in its lifetime that occur using lvalues which might not be derived from it are sequenced with regard to each other and with regard to the beginning and end of that lifetime, but operations in the two groups may be arbitrarily interleaved.   *p1 = 1;

  *p2 = 2;
}

  int * restrict p1 = &p1_temp;

{
    const int Base = 10;

    while ( n1 != 0 && n2 != 0 )
