{
    struct tnode s;
    return &s;
}

the struct is allocated on the stack and automatically free'd when the function exits. Thus, your returned pointer becomes a dangling pointer which you cannot use (outside the function). Once execution leaves the block, the storage that had been used to hold the struct tnode will be eligible to be reused for other purposes.

In detail, there must be two bytes in a zlib header:
0   1
+---+---+
|CMF|FLG|
+---+---+

First byte (CMF):
Each nibble (half-byte) of the first byte has a meaning:
bits 0 to 3  CM     Compression method
bits 4 to 7  CINFO  Compression info

You can see it in more detail in the answer I've mentioned above.

FLG (FLaGs) This flag byte is divided as follows:
bits 0 to 4  FCHECK  (check bits for CMF and FLG)
bit  5       FDICT   (preset dictionary)
bits 6 to 7  FLEVEL  (compression level)

The most common headers are:
78 01 - No Compression/low
78 9C - Default Compression
78 DA - Best Compression
